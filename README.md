# Cars Dealership - Full-stack Development Capstone Project

## Project Overview
This is a full-stack web application developed for Care Dealership, a national car retailer in the U.S. The application allows users to view dealership branches across the country and submit reviews.

## Technologies Used
- Frontend: React, HTML5, CSS3, JavaScript
- Backend: Django, Flask, Node.js
- Database: MongoDB, SQLite
- Deployment & Cloud: Docker, Kubernetes, IBM Cloud Code Engine
- CI/CD: GitHub Actions
